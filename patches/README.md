wine-11.20 (tag `wine-11.20`) on 2026-10-28: 89 files. Complete on its own: apply every `*.patch` here in name
order with `patch -Np1` (all apply with `-F0`, no fuzz). wine/patches stays the 11.18 set until the laptop
moves. This supersedes wine/patches-11.19, which was never brought past 0076.
